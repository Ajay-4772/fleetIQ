# FleetIQ — Data Sources Specification

This document details all data sources referenced, evaluated, or utilized within the FleetIQ platform.

---

## 1. Summary of Data Strategy

FleetIQ adheres to a strict three-tier data hierarchy:

1. **Synthetic Multi-OEM Telemetry (Primary Operational Layer)**
   - All real-time telemetry, diagnostic fault codes (DTCs), sensor readings, utilization, and operational events are generated by FleetIQ's reproducible in-house simulator.
   - Purpose: Real-time simulation, edge case generation, multi-OEM schema normalization, load testing, and platform demonstration.
   - Source: In-house synthetic simulator (`src/main/java/com/fleetiq/service/simulator/`).

2. **Public / Open Datasets (Reference & Seed Layer)**
   - Used exclusively for real-world vehicle metadata validation (makes, models, years, fuel types, standard DTC fault descriptions).
   - Never treated as live vehicle telemetry.
   - Explicitly verified for open access, public domain status, or permissive open-source licensing.

3. **Deterministic Test Fixtures (Testing Layer)**
   - Isolated, static test fixtures located in `src/test/resources/`.
   - Never dependent on network calls or external API availability.

## 2. Public / Open Datasets

### A. NHTSA vPIC (Vehicle Product Information Catalog) API
- **Official Source**: National Highway Traffic Safety Administration (NHTSA), U.S. Department of Transportation
- **Official URL**: https://vpic.nhtsa.dot.gov/api/
- **Provider**: U.S. Federal Government
- **Access Date**: 2026-09-25
- **License / Terms**: Public Domain (U.S. Government Work under 17 U.S.C. § 105). Freely accessible for public and commercial use without copyright restrictions.
- **Allowed Use**: Full reuse, reproduction, and redistribution.
- **Attribution**: Recommended acknowledgment of NHTSA as the data source.
- **FleetIQ Utilization**: Reference schema for vehicle makes, models, model years, and vehicle types to construct realistic synthetic seed vehicle catalogs (`data/synthetic/vehicles/vehicle_models.csv`).
- **Boundaries**: NHTSA data is never used as real-time vehicle telemetry or live incident reporting.

### B. NHTSA Safety Recalls & Defects Database (Optional Reference)
- **Official Source**: NHTSA Office of Defects Investigation (ODI)
- **Official URL**: https://www.nhtsa.gov/recalls
- **Provider**: U.S. Federal Government
- **Access Date**: 2026-09-25
- **License**: Public Domain (17 U.S.C. § 105).
- **FleetIQ Utilization**: Real-world fault category taxonomies (e.g., steering gear, powertrain, electrical systems) used to calibrate synthetic scenario generation (`data/synthetic/faults/fault_codes.csv`).
- **Operational Rule**: Public recall data is never mapped to individual simulated vehicles as real-time telemetry events.

### C. UCI Machine Learning Repository — Auto MPG & Automobile Datasets
- **Official Source**: University of California, Irvine (UCI) Machine Learning Repository
- **Official URLs**:
  - Auto MPG: https://archive.ics.uci.edu/dataset/9/auto+mpg
  - Automobile: https://archive.ics.uci.edu/dataset/10/automobile
- **Provider**: UC Irvine Center for Machine Learning and Intelligent Systems
- **License**: Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Attribution**: Required attribution preserved in `docs/DATA_LICENSES.md` and `README.md`.
- **FleetIQ Utilization**: Reference baseline for typical vehicle fuel efficiency (MPG / liters per 100km), displacement, and weight distributions used by the synthetic telemetry generator to assign realistic fuel burn rates during idling and driving.

## 3. Evaluated & Rejected Sources

| Source Evaluated | Decision | Rationale |
| :--- | :--- | :--- |
| **Motorq Proprietary Telemetry / APIs** | **STRICTLY PROHIBITED** | FleetIQ is an independent engineering project. No proprietary Motorq APIs, datasets, credentials, customer data, or internal schemas are permitted or used. |
| **Kaggle Unverified Datasets** | **REJECTED** | Arbitrary vehicle/fleet datasets on Kaggle frequently contain restrictive, non-commercial, or ambiguous licensing terms. Rejected to maintain 100% license compliance. |
| **Scraped OEM Telemetry Streams** | **REJECTED** | Violates OEM terms of service and poses intellectual property concerns. Synthetic OEM format adapters are used instead. |
| **Real Customer / VIN Records** | **REJECTED** | Real VINs and personal identifiers pose privacy risks. FleetIQ utilizes purely synthetic VIN-like formats (e.g., `1FTFW1ED4NFA90001-SYNTH`). |
